## Project Overview

Greats Language Center (GLC) is looking to develop an AI-enabled learning and assessment platform for our online English language center. The project has two main components:

1. AI Placement Test for prospective students
2. 24/7 AI Tutor for current students

GLC serves primarily Arabic-speaking English learners and currently uses materials including Beehive, Oxford English File, Smart Choice, and other approved learning resources. The platform should be practical, student-friendly, scalable, and suitable for both school-age learners and adult learners.

## Module 1: AI Placement Test

We want prospective students to complete an online placement test that assesses their English level across the main language skills:

- Reading
- Writing
- Listening
- Speaking

The placement test should produce a clear level recommendation for GLC's course structure, such as Starter, Beginner, Elementary, Pre-Intermediate, Intermediate, Upper-Intermediate, or Advanced.

### Required Features

The placement test should include:

- Student registration / test entry page
- Reading questions
- Listening questions using audio
- Writing task with AI-assisted evaluation
- Speaking task using voice recording or speech-to-text
- AI-assisted scoring based on clear criteria
- Recommended GLC level
- Skill-by-skill summary
- Admin review dashboard
- PDF placement report / certificate generated automatically

The AI result should be reviewable by GLC before final confirmation, especially for borderline cases.

## Module 2: 24/7 AI Tutor

We also want a 24/7 AI Tutor for current GLC students. The tutor should be grounded in our approved curriculum and help students practise English outside class.

### Required Features

The AI Tutor should be able to:

- Explain grammar and vocabulary from GLC-approved materials
- Answer student questions based on their current level/unit
- Help with reading, writing, listening, and speaking practice
- Correct short writing tasks
- Generate simple quizzes and revision exercises
- Provide hints and explanations instead of simply giving homework answers
- Adapt responses to the student's level
- Track student usage and progress

The system should allow GLC to upload, organise, update, and remove curriculum materials over time.

## Admin / Teacher Dashboard

The platform should include a simple dashboard for GLC staff to:

- View placement test results
- Review AI level recommendations
- Access student reports
- Monitor AI Tutor usage
- See common student weaknesses
- Review writing submissions or quiz attempts
- Export or download reports where needed

## Technical Expectations

We are open to the developer's recommended technical approach, but the platform should ideally be:

- Web-based
- Mobile-friendly
- Secure and easy for students to access
- Suitable for 100–150 students initially
- Able to generate PDF reports
- Built with role-based access for admin, teachers, and students
- Designed so GLC can update content without needing a developer each time

Optional future features may include WhatsApp integration, parent dashboard, gamification, pronunciation scoring, and mobile app support. These can be quoted or scoped separately.

## Data Protection & Student Safety

Because the platform may be used by minors, the system should include appropriate privacy and safety protections, including:

- Secure login
- Controlled access to student data
- Admin-only access to reports and results
- Safe AI responses
- Clear logs or review ability where needed
- Ability to delete or export student records if required

## Expected Deliverables

We would like the developer to propose a clear phased plan covering:

1. Requirements confirmation

3. AI Placement Test module
4. AI Tutor module
5. Curriculum upload / knowledge base system
6. Admin / teacher dashboard
7. PDF placement report / certificate generation
8. Deployment
